# Word 写作规范

这套规范的目标不是限制写作，而是让 Word 的语义可以稳定转换为 Markdown。

## 推荐使用

- 文章名：使用 Word 的“标题”样式，或只在导入时填写；
- 章：使用“标题 1”；
- 节：使用“标题 2”；
- 小节：使用“标题 3”；
- 正文：使用“正文”或“普通”；
- 引文：使用“引用”样式；
- 强调：使用真正的加粗或斜体；
- 图片：使用“插入图片”，尽量填写替代文字或图片说明；
- 简单表格：可以使用，导入后应人工检查。

导入器会保留自然段，不会按句号拆段。Word 的“标题 1—3”分别转换为
Markdown 的 `#`、`##`、`###`；引用样式转换为 `>`；图片提取为 WebP，
并在 `images/original/` 保留原图。

## 尽量避免

- 用大量空格或 Tab 对齐；
- 用许多空行制造页距；
- 文本框、艺术字和浮动形状；
- 把文字写在图片中；
- 复杂合并单元格；
- 页面绝对定位、多栏和环绕排版；
- 依赖 Word 页眉、页脚或页码表达正文；
- 链接到本机文件或网络图片。

这些是纸张版式而不是文章结构，无法稳定映射到响应式网页。导入器会报告文本框、
复杂表格、空段落、外部链接和无法转换的图片，但不会访问外部地址。

## 图片建议

- 优先插入 PNG、JPEG 或 WebP；
- 建议单张小于 5MB；
- 导入器最长边限制为 2400px，不会放大小图；
- 动图、SVG、WMF、EMF 等不能可靠转换时会保留原文件并提示检查；
- 原图不会删除。

## slug 规则

slug 决定永久链接，只允许：

```text
小写英文字母 + 数字 + 连字符
```

例如 `renzong-ji`。不要用标题自动生成 URL；修改标题时不要随意修改 slug。

## 导入后必须检查

- 标题层级是否正确；
- 图片位置与说明是否正确；
- 引用、粗体和斜体是否完整；
- 表格是否需要人工整理；
- 自动摘要是否合适；
- 草稿状态是否正确；
- 页面目录、上一篇/下一篇和文集归属是否正确。
