# 快速开始

1. 安装 Node.js 22+、Python 3 和 Hugo Extended。
2. 安装 `importer/requirements.txt` 与 `comments-service` 依赖。
3. 不创建工作区配置，运行 `npm run build` 验证虚构 demo。
4. 运行 `npm run comments:init`，再运行 `npm run comments:create-admin`。
5. 运行 `npm run dev`，访问终端显示的回环地址。
6. 运行 `npm run studio` 编辑 demo 临时副本；重启前请把需要保留的内容转入私人仓库。

生产环境不要沿用 demo 密钥、路径或域名。
