# 图片处理

## 放置方式

图片与文章的 `index.md` 放在同一目录，用普通 Markdown 引用：

```markdown
![图片替代文字](image-01.jpg "图片说明")
```

Hugo 构建时自动生成最多 480、960、1440 像素的 WebP 响应式版本。低分辨率图片不会被放大。正文使用中等尺寸，点击可查看较大版本。

## 封面

文集目录中放置 `cover.jpg`、`cover.png` 或 `cover.webp`。没有封面时会显示克制的文字占位，不影响构建。

## 建议

- 保留原图。
- 优先使用 JPEG、PNG 或 WebP。
- 上传前删除不必要的 EXIF 位置信息。
- 普通正文图片建议长边不超过 2400px。
- 单张超过 5MB 时构建会给出非阻断警告。
- 非首屏图片自动延迟加载并写入明确宽高，减少页面跳动。

`scripts/check-images.sh` 会检查格式、体积和 Markdown 引用完整性。已在原稿中引用但不存在的图片会阻止发布；超大或扩展名可疑的普通图片只给出警告，不会删除原图，也不会自动改写原稿。
