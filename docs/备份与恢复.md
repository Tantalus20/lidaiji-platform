# 备份与恢复

## 本地备份

```bash
sudo ./scripts/backup.sh
```

备份包含 Markdown、图片、`data/author-notes/` 作者评、Hugo配置、主题、脚本、Nginx模板和文档；若当前目录已初始化 Git，还会生成 Git bundle 与提交号。每个压缩包都有 SHA-256 校验文件。

默认目录是 `/var/backups/writing-site/`，与源码和 Nginx 发布目录隔离。Mac 本地可改到个人文档目录：

```bash
WRITING_BACKUP_DIR="$HOME/Documents/历代纪备份" ./scripts/backup.sh
```

双击 `backup.command` 时会自动使用上述 Mac 目录。目标目录会自动创建，但不可写时会明确报错。备份采用白名单，只包含 `content`、`data`、`config`、`themes`、`scripts`、`docs`、`archetypes`、`static`、`deploy` 及项目说明；不会包含 `.env`、Git目录、构建缓存、`node_modules` 或项目内备份。

源码备份包含段评服务代码和配置模板，但明确排除 SQLite、`.env` 和运行数据。
`dist/site` 可以重新生成，不代替源码备份；评论数据另见《段评备份与迁移》。

## 恢复演练

```bash
./scripts/restore-local.sh "$HOME/Documents/历代纪备份/writing-site-source_时间戳.tar.gz" /tmp/writing-site-restored
cd /tmp/writing-site-restored
./scripts/install-hugo-macos.sh
./scripts/check.sh
```

恢复目标必须是不存在的新目录，避免覆盖当前原稿。

## 服务器手动备份

```bash
sudo /opt/writing-site/source/scripts/server-backup.sh
```

手动备份生成 `.keep` 标记，不会被自动清理。自动发布前备份默认保留最近 7 份。

## 新服务器恢复

1. 校验源码压缩包。
2. 解压到 `/opt/writing-site/source`。
3. 在 Mac 或新服务器安装 Hugo固定版本并运行检查。
4. 配置独立 Nginx 站点和证书。
5. 发布静态 release。
6. 检查首页、文章、RSS、站点地图和搜索。

备份永远放在 `/var/backups/writing-site` 或明确指定的项目外目录，不得放入源码、release 或 Nginx 根目录。
