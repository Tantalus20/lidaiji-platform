# 安全说明

正文仍是纯静态阅读站：

- 无游客注册、社交登录、投稿、点赞、会员、邮件订阅和公开上传。
- 段评由独立服务保存；所有新段评默认待审核，公共接口只返回已通过内容。
- 站主管理后台使用 scrypt 密码、服务端 Session、Secure Cookie、CSRF 和登录限流。
- 无远程字体、统计、CDN脚本、第三方搜索或外部嵌入。
- 搜索在访客浏览器本地完成，关键词不发送到服务器。
- 搜索结果使用 `textContent` 创建，不把索引内容写入 `innerHTML`。
- Front Matter 由 Hugo 模板自动转义；Goldmark禁止不安全原始HTML。
- 页面没有内联事件处理器。

Nginx模板设置 CSP、`X-Content-Type-Options`、`Referrer-Policy`、`Permissions-Policy` 和 `frame-ancestors 'none'`，并阻止 Markdown、脚本、环境文件、备份和隐藏文件访问。

发布包只包含 `dist/site`，不会包含 `.git`、`.env`、Markdown、脚本和备份。自动检查会再次验证。

正文作者仍通过本地文件、Git、SSH和VPN管理。段评后台只能审核评论，不能在线
修改文章。SQLite、环境变量、日志和备份均在 Nginx 静态目录之外。
