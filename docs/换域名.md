# 换域名

1. 将新域名解析到服务器并取得 HTTPS 证书。
2. 修改本地预览默认地址时，调整 `config/_default/hugo.toml` 的 `baseURL`；正式发布会由 `WRITING_DOMAIN` 覆盖。
3. 生成新域名的独立配置：

   ```bash
   ./scripts/render-nginx-config.sh 新域名
   ```

4. 安装新 Nginx 配置，先运行 `sudo nginx -t`，成功后才能 reload。
5. 用新域名重新构建并发布：

   ```bash
   WRITING_DOMAIN=新域名 WRITING_SSH_TARGET=root@服务器IP ./scripts/publish.sh
   ```

6. 旧域名保留一段时间，并用独立 server 块把旧地址 301 到对应的新路径。
7. 检查 canonical、RSS、站点地图和搜索索引都使用新域名。

文章路径由目录和显式 `slug` 控制，修改标题或域名不会改变路径。文章曾经改过路径时，在 Front Matter 的 `aliases` 中加入旧路径，由 Hugo 生成兼容跳转页。
