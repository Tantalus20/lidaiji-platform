# 故障排查

## 提示未找到Hugo

运行：

```bash
./scripts/install-hugo-macos.sh
```

它把校验后的 Hugo 固定版本安装到项目内的 `.hugo-local`，不修改系统目录。

## 预览窗口一闪而过

从终端运行 `./scripts/preview.sh` 查看完整错误；双击 `.command` 在失败时会等待回车，不会立即关闭。

## 新文章没有显示

检查：

- `draft` 是否仍为 `true`。
- 日期是否在未来。
- `index.md` 是否位于正确 Page Bundle 目录。
- YAML 的引号和列表是否成对。

## 图片不显示

图片必须与文章 `index.md` 位于同一目录，Markdown路径区分大小写。缺图不会阻止整站构建，但自动检查和页面占位会提示。

## 发布失败

旧站不会被替换。检查本地构建、SSH、域名证书、Nginx配置与服务器磁盘。不要为修复文章站而重启游戏或骰娘。

## Nginx配置失败

不要 reload。运行 `nginx -t` 阅读具体文件和行号，修正独立文章站配置后再次检查。

## 搜索无结果

确认 `/search-index.json` 返回200，重新运行 `./scripts/check.sh`。索引只包含已公开的正式文章，每篇正文最多索引配置中指定的字符数。

## 手机横向滚动

通常由文章中的超宽表格、长链接或大图引起。主题会让表格在自身区域滚动；若仍出现，检查文章是否包含无法换行的超长连续字符串。
