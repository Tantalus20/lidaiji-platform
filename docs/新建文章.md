# 新建文章

运行：

```bash
./scripts/new-post.sh
```

脚本会询问内容类型、标题、稳定 slug、所属文集、分类和是否为草稿。

## slug 规则

使用小写英文、数字和连字符，例如：

```text
renzong-ji
school-memories-01
```

文章标题可以任意修改；只要目录和 `slug` 不变，永久链接就不变。

## Front Matter

```yaml
---
title: "文章标题"
subtitle: ""
date: 2026-07-28
lastmod: 2026-07-28
slug: "stable-slug"
description: ""
draft: true
featured: false
weight: 10
collections: ["文集名称"]
categories: ["分类"]
tags: ["标签"]
series: ["系列"]
period: ["时期"]
people: []
places: []
aliases: ["/旧链接/"]
---
```

`people`、`period`、`places` 是可选的人物、时期和地点索引字段，不应把真实人物写入主题模板。`aliases` 会为旧地址生成跳转页。

## 新建文集

复制一个文集目录结构，创建：

```text
content/works/新文集slug/_index.md
```

在 `_index.md` 中设置 `layout: "collection"`、`status: "连载中"` 或 `status: "已完结"`。篇数和总字数由站点自动计算。
