# 本地写作

## 原稿在哪里

所有权威原稿都在 `content/`。每篇文章是一个 Page Bundle：

```text
content/works/文集slug/文章slug/
├── index.md
├── cover.jpg
└── image-01.png
```

不要把 `dist/site/` 中的 HTML 当作原稿。它随时可以由 Markdown 重新生成。

## 推荐流程

1. 双击 `new-post.command` 建立文章目录。
2. 使用任意纯文本或 Markdown 编辑器修改 `index.md`。
3. 把图片放在同一文章目录。
4. 双击 `preview.command`。
5. 浏览器打开 `http://127.0.0.1:1313/`。
6. 完成后将 `draft: true` 改为 `draft: false`。
7. 运行 `./scripts/check.sh`。
8. 提交 Git，再备份或发布。

## 内容自主权

文章使用通用 YAML Front Matter、普通 Markdown 和普通图片。不需要平台账号，离线也能编辑。三个必要短代码 `center`、`small`、`mark` 都有简单的 HTML/Markdown 替代方式，详见迁移文档。
