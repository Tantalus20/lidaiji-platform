# 段评备份与迁移

评论数据库与文章源码分别备份。默认位置：

```text
/var/lib/lidaiji-comments/comments.sqlite3
/var/backups/lidaiji-comments/
```

一致性备份：

```bash
sudo /opt/writing-site/source/scripts/comments-backup.sh
```

压缩包包含 SQLite 快照、schema 版本、当前评论 manifest 和配置模板，不包含
真实环境变量、管理员密码明文或服务器密钥。每份备份附 SHA-256。

恢复：

```bash
sudo /opt/writing-site/source/scripts/comments-restore.sh \
  /var/backups/lidaiji-comments/lidaiji-comments_时间.tar.gz --confirm
```

脚本先校验 SQLite、再备份当前数据库、停止段评服务、原子替换并重新启动。
文章静态站不受停止影响。

导出公开档案：

```bash
sudo /opt/writing-site/source/scripts/comments-export.sh
```

完整审计导出：

```bash
sudo /opt/writing-site/source/scripts/comments-export.sh \
  /安全目录/comments-export audit
```

JSON 恢复必须先同步当前文章 manifest，再运行：

```bash
node --experimental-sqlite /opt/lidaiji-comments/current/src/cli.js import-json comments.json
```

迁移到新服务器时复制源码、静态站和评论备份；创建评论专用系统用户，恢复
数据库，部署相同 revision 的静态 release，最后检查文章锚点和公共 API。
更换域名只需修改 Hugo `baseURL`、Nginx `server_name` 及
`COMMENTS_PUBLIC_ORIGIN`，articleId 和 paragraphId 不变。
