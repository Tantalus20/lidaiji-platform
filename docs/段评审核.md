# 段评审核

正式后台地址为 `https://你的域名/admin/comments/`。管理员密码使用 scrypt
保存，源码和环境文件均不含明文。首次部署后在服务器运行：

```bash
printf '%s' '你的高强度密码' |
sudo -u lidaiji-comments --preserve-environment \
node --experimental-sqlite /opt/lidaiji-comments/current/src/cli.js create-admin owner
```

后台可以按状态、文章 ID、昵称或正文、是否含链接和是否疑似重复筛选，并以
25 条一页显示。审核卡片同时展示当前段落、提交时摘录、文章 revision 和原文
锚点。可以通过、拒绝、标记垃圾、隐藏或逻辑删除；也可以批量通过、拒绝或
标记垃圾。批量通过前会再次确认。

登录 Cookie 使用 `HttpOnly`、`Secure` 和 `SameSite=Strict`；所有写操作同时
检查服务器会话和 CSRF token。登录失败使用统一提示并限流。不要把管理员
令牌复制到 URL，也不要把 `/etc/lidaiji-comments.env` 放入源码备份。
