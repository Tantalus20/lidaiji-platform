# 游客段评系统

V0.3.0 保留 Hugo 静态正文，只增加一个独立的小型段评服务。服务停止时，
所有文章仍能正常打开；段评按钮会提示暂时不可用，不会让正文白屏。

## 稳定身份

每篇开放段评的文章在 Front Matter 中保存：

```yaml
articleId: article-a11da1e000000001
articleRevision: article-a11da1e000000001@c1603371662c
comments:
  paragraph: true
```

`articleId` 创建后不随标题、slug 或永久链接变化。正文自然段前保存：

```markdown
<!-- paragraph-id:p-30caf8624001 -->

正文自然段。
```

这是一条普通 Markdown 注释，换主题或迁移工具时可以保留。构建脚本把同一
ID 写入 HTML 的 `id` 与 `data-paragraph-id`，并生成
`comment-manifest.json`。重复 `articleId`、重复段落 ID 或无法匹配生成页面
都会使构建失败。

Word 重导入先读取旧稿，综合标准化文本、标题上下文、相对位置和文本相似度
匹配。完全相同的重复段落按上下文与顺序区分；低置信匹配不复用旧 ID，只在
导入报告中要求人工检查。删除段落不会删除评论，服务同步 manifest 时把评论
标记为 `orphaned`。

## 游客流程

读者打开文章时只请求一次段评数量映射。点击具体段落后才读取该段已通过
评论。提交只收昵称、纯文本段评和公开确认，不收邮箱；所有正常提交固定进入
`pending`，只有站主审核为 `approved` 后公共 API 才会返回。

昵称 1—40 字，正文 5—3000 字。服务拒绝 HTML、控制字符、危险协议和超过
两个外部 URL。蜜罐、重复内容、来源与分时段限流共同用于防垃圾。原始 IP
不写入评论表，只保存使用服务器私密盐生成的不可逆 HMAC。

文章开关：

```yaml
comments:
  paragraph: true    # 展示并接受新段评
```

```yaml
comments:
  paragraph: locked  # 展示已通过段评，不接受新提交
```

```yaml
comments:
  paragraph: false   # 不加载段评脚本
```

## 章评（V0.4.0）

章评是针对整篇文章的整体评论，与段评共用同一服务、同一数据库表、同一
审核后台和同一套限流与安全规则，仅以 `scope` 区分：

```text
段评：scope=paragraph，paragraph_id 必填（关联自然段）
章评：scope=article，paragraph_id 为空（只关联 article_id）
```

`scope` 由数据库触发器强制约束；V0.3.x 旧段评在迁移时自动视为
`paragraph`，ID、状态、关联与时间不变。结构性迁移执行前服务会自动把
数据库 VACUUM 备份到 `comments.sqlite3.pre-v<版本>-<时间>.bak`。

章评区域位于文章页上下篇导航之后（`#article-comments`），默认显示前 5 条
已通过章评，"查看更多"分页加载。章评正文 10—3000 字，其余校验、蜜罐、
限流、审核流程与段评一致。计数接口在原有 `counts` 映射之外新增
`articleCount` 字段，旧前端忽略该字段，向后兼容。

公开列表：

```text
GET /api/comments/v1/articles/{articleId}/article-comments?offset=0&limit=5
```

提交与段评同一路由 `POST /api/comments/v1/comments`，携带
`"scope": "article"` 与 `articleId` 即可。后台筛选新增"类型"（全部/段评/
章评），章评不显示段落 ID，跳转链接指向文章页章评区。

## 本地运行

```bash
COMMENTS_DATA_DIR="$PWD/.cache/comments-local" \
COMMENTS_DB="$PWD/.cache/comments-local/comments.sqlite3" \
COMMENTS_PUBLIC_ORIGIN=http://127.0.0.1:4317 \
COMMENTS_HMAC_SECRET=local-development-secret-32-bytes-minimum \
./scripts/comments-local.sh
```

首次建立站主：

```bash
printf '%s' '至少十二位的本地测试密码' |
COMMENTS_DB="$PWD/.cache/comments-local/comments.sqlite3" \
node --experimental-sqlite comments-service/src/cli.js create-admin owner
```

浏览器访问 `http://127.0.0.1:4317/`；审核后台是
`http://127.0.0.1:4317/admin/comments/`。

## 状态

`pending` 等待审核；`approved` 公开；`rejected` 拒绝；`spam` 垃圾；
`hidden` 曾公开后隐藏；`deleted` 逻辑删除；`orphaned` 原段落已不存在。
公共接口只读取 `approved`。所有审核动作另存于 `moderation_actions`，不会
悄悄改写游客原文。
