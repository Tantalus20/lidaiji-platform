# 迁移网站

## 换主题

原稿位于 `content/`，主题位于 `themes/lidaiji/`。新主题只需理解通用 Front Matter。保留永久链接配置和 slug 即可。

## 换静态站工具

Markdown、YAML和图片都可直接读取。迁移时：

1. 将 `_index.md` 转为目标工具的集合页。
2. 保留 `slug`、`aliases`、日期、分类和标签。
3. 把三个短代码替换为普通 Markdown/HTML：
   - `center`：居中段落，可退化为普通段落。
   - `small`：小号说明，可退化为普通段落。
   - `mark`：强调段落，可替换为粗体或引用。
4. 根据旧 `aliases` 建立跳转。

## 换服务器

1. 从 `/var/backups/writing-site/` 或 Mac 外部备份目录复制源码压缩包、`.sha256`、Git bundle 和 commit 文件。
2. 用 `shasum -a 256 -c 文件.sha256`（Linux 使用 `sha256sum -c`）验证。
3. 解压到新机器的 `/opt/writing-site/source/`，确认 `content/`、图片、`config/` 和 `themes/` 完整。
4. 恢复 Git 历史时运行 `git clone writing-site-git_时间.bundle source-with-history`；不需要历史时可直接使用源码压缩包。
5. 安装项目锁定版本的 Hugo，运行 `./scripts/check.sh` 重新生成静态站。
6. 将生成结果放入 `/opt/writing-site/releases/<时间戳>/`，再原子设置 `/opt/writing-site/current` 软链接。
7. 安装独立 Nginx 配置和证书，执行 `nginx -t` 后 reload。
8. 验证首页、长文、搜索、RSS、站点地图与 404。

Markdown 与图片的导出就是复制 `content/`；Hugo 配置位于 `config/`，主题位于 `themes/lidaiji/`。不要只迁移生成后的 HTML。

## 恢复历史release

若备份了 `/opt/writing-site/releases/`，可将某个完整 release 放回同一路径，并执行：

```bash
sudo /opt/writing-site/source/scripts/server-rollback.sh /opt/writing-site/releases/目标时间戳
```

release 只用于快速回滚，不能代替 Markdown 源码备份。

## PDF与电子书

文章均为普通 Markdown，可使用 Pandoc 批量转换：

```bash
pandoc content/works/文集/文章/index.md -o 文章.pdf
```

也可以使用浏览器打印样式逐篇导出 PDF。批量电子书时应先把 Page Bundle 图片路径转换为目标工具可识别的路径。

## 完整可导出项目

- 原稿：`content/`
- 配置：`config/`
- 主题：`themes/lidaiji/`
- 静态HTML、RSS、站点地图：`dist/site/`
- Git历史：`.git/` 或备份生成的 `.bundle`
