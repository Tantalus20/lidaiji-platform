# 部署服务器

## 目标结构

```text
/opt/writing-site/source/             Markdown与源码
/opt/writing-site/releases/<时间戳>/  静态release
/opt/writing-site/current             当前release软链接
/var/backups/writing-site/            非公开备份
/opt/lidaiji-comments/releases/       独立评论服务release
/var/lib/lidaiji-comments/            非公开SQLite数据库
/var/backups/lidaiji-comments/        评论数据库备份
```

Nginx只读取 `/opt/writing-site/current`。Hugo只在本地构建，不常驻服务器。

## 首次部署准备

1. 为文章站准备独立域名解析。
2. 渲染独立 Nginx 配置：

   ```bash
   ./scripts/render-nginx-config.sh 你的域名
   ```

3. 在服务器取得该域名的 HTTPS 证书。
4. 将生成配置单独放入 Nginx `sites-available`，建立 `sites-enabled` 软链接。
5. 运行 `nginx -t`，成功后才 `systemctl reload nginx`。
6. 设置 `WRITING_DOMAIN` 后运行 `sudo scripts/comments-install-server.sh /opt/writing-site/source`。
7. 在第一次发布后通过标准输入创建站主账号，参见《段评审核》。
8. 不修改游戏站点配置或 WebSocket 代理。

## 日常发布

```bash
export WRITING_SSH_TARGET=root@服务器IP
export WRITING_DOMAIN=你的文章域名
./scripts/publish.sh
```

脚本会要求输入“发布”确认。它先本地检查、构建和备份，再上传静态站、源码
和独立段评服务包。服务器先备份 SQLite，再迁移和同步评论 manifest；成功后
才切换静态 release。任一步失败都会恢复旧静态站、旧评论服务和发布前数据库。

源码包不是对工作区做宽泛压缩，而是由 `scripts/create-source-package.sh` 从
已提交 Git 对象生成，并同时输出 `.manifest.txt` 与 `.sha256`。因此未跟踪的
缓存、SQLite、Word、`.env*`、`.author-settings`、构建产物、日志、截图和
macOS `._*`/`.DS_Store` 不会进入服务器源码 release。

发布脚本只重启独立 `lidaiji-comments` 服务，不会重启或终止《澄清南北
Online》、骰娘、NapCat 或其他 Node 进程。日常文章发布不需要 reload Nginx。

## 回滚

```bash
ssh root@服务器IP
WRITING_DOMAIN=你的域名 /opt/writing-site/source/scripts/server-rollback.sh \
  /opt/writing-site/releases/目标时间戳
```

回滚会一起切换对应的段评服务、同步该版本的段落清单，并先备份当前评论
数据库；健康检查失败时，静态站、段评服务和数据库会一起恢复。服务器默认
同时保留最近 5 个静态 release 和对应的段评服务 release。
