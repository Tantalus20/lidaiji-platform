# 预览与构建

## 预览

```bash
./scripts/preview.sh
```

预览包含草稿，只监听 `127.0.0.1:1313`，不会向公网开放。按 `Control+C` 停止。

## 正式构建

```bash
./scripts/check.sh
```

构建流程：

1. 检查图片格式、大小和引用完整性。
2. Hugo 在临时目录生成正式站，不包含草稿。
3. 检查页面、内部链接、资源、安全字段、RSS、搜索索引、三万字与十万字长文。
4. 全部成功后才把临时目录原子替换为 `dist/site/`。
5. 失败时保留上一份 `dist/site/`。

指定正式域名：

```bash
SITE_BASE_URL=https://你的域名/ ./scripts/check.sh
```

CSS 与 JavaScript 会生成带内容指纹的文件名。HTML短缓存，指纹资源可长期缓存。
